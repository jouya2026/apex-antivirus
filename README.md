# APEX Antivirus

A lightweight Windows security application (Security · Performance · Privacy · Identity) with a bilingual English/Dari interface.

This repository hosts the official **release downloads** for APEX Antivirus. The installer and update files are published under the [Releases](../../releases) section.

## Install

Download the latest `APEX-Antivirus-Setup-x.x.x.exe` from the [Releases](../../releases) page and run it.

## Updates

APEX Antivirus updates itself automatically. There is nothing to do manually.

## About

APEX Antivirus is a legitimate security product developed by APEX Software. It provides on-demand and folder-watch scanning, system performance tools, privacy tools, and identity protection.
